Autonomous Forklifts (AFL) Nov 2024 · Oct 2025
Mobyus Future Tech R&D Lab
Key results: ≤30 mm SLAM position error (testbeds); pallet-hole detection @ 4 m with ~0.5° angular error. My role: algorithm design/implementation, integration on real platforms, and evaluation/validation. Tech: ROS 2, LiDAR, IMU, RGB-D (RealSense), stereo (ZED2i), SICK LiDAR, SICK Visionary-T Mini, PCL/OpenCV, PyTorch.
Demo: autonomous forklift navigation + docking (planning/control + SLAM)
  • Navigation & control: developed Frenet-frame optimal-trajectory planning with B-spline smoothing for obstacle avoidance and precise docking; implemented a three-wheeled controller on an AFL platform (SD-type motors).
  • State estimation (SLAM): built a local mapping + localization pipeline integrating LiDAR/IMU with ESKF; tuned for stable pose and reliable operation in real deployments; integrated PLC-triggered behaviors for production workflows.
Demo: depth camera + LiDAR fusion for obstacle detection and safe navigation
  • Perception & fusion: developed obstacle detection using sensor fusion of RealSense D435f depth data and a 2D SICK LiDAR to improve robustness under occlusion and dynamic scenes.
  • Validation: stress-tested detection behavior and navigation safety in real aisles with moving objects and varied lighting/reflective surfaces.
Demo: pallet-hole center estimation (Visionary-T Mini) + truck free-space estimation (ZED2i)
  • Precision perception: developed pallet-stacking perception using SICK Visionary-T Mini; estimated pallet size and fork-pocket (hole) centers with a transformer-based model + CAD prior for precise insertion/alignment.
  • Scene understanding: built truck/trailer free-space perception using ZED2i stereo and object detectors (YOLOv12, RF-DETR) to estimate available loading space and placement feasibility.
